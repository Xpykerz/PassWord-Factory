# PassWord Factory

PassWord Factory is a powerful wordlist generator designed for penetration testers and security enthusiasts. It allows users to create wordlists using either a standard character set or a custom-defined character set. The tool generates all possible combinations and permutations efficiently. Developed by @Xpykerz, PassWord Factory is written in Python and is compatible with Linux, Windows, and Android platforms.

## Installation

### Linux

To install and run PassWord Factory on Linux:

```
apt-get update && apt-get upgrade
apt install python
apt install git
git clone https://github.com/Xpykerz/PassWord-Factory.git
cd PassWord-Factory
chmod +x PassFact.py
./PassFact.py
```

### Android

To install and run PassWord Factory on Android:

```
apt-get update && apt-get upgrade
apt install python2
apt install git
git clone https://github.com/Xpykerz/PassWord-Factory.git
cd PassWord-Factory
python2 PassFact.py
```
